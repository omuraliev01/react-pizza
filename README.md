# 🍕 React Pizza

A responsive and interactive pizza ordering web application built with React and Redux. This project serves as a frontend clone of a pizza delivery service, complete with category filtering, sorting, and a fully functional shopping cart.

## ✨ Features

* **Dynamic Catalog:** Browse a variety of pizzas fetched directly from a mock REST API.
* **Filter & Sort:** Easily filter pizzas by category (Meat, Vegetarian, Grill, Spicy, Closed) and sort them by popularity, price, or name.
* **Customizable Orders:** Select pizza size and dough type before adding to the cart.
* **Shopping Cart:** Add or remove items, adjust quantities, and view real-time total price calculations.
* **Responsive Design:** Fully styled using SCSS for a clean, modern user interface.

## 🛠️ Tech Stack

* **Frontend:** React (Hooks), React Router DOM
* **State Management:** Redux, Redux Thunk
* **Styling:** SCSS (Sass), classnames
* **API / Network:** Axios
* **Backend Mock:** JSON Server
